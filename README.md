# review-assigner
A service for assinging pull request reviewers.

## Допущения
- > При создании PR автоматически назначаются до двух активных ревьюверов

  При наличии в команде хотя бы двух ревьюеров, назначается два

- При добавлении новой команды с уже существующим пользователем возвращается 403,
  т.к. этот пользователь может быть уже назначен ревьюером в другой команде и в таком случае
  он не должен менять команду
