# review-assigner (Тестовое задание для стажёра Backend в Avito)
Cервис, который назначает ревьюеров на PR из команды автора, позволяет выполнять переназначение ревьюверов и получать список PR’ов, назначенных конкретному пользователю, а также управлять командами и активностью пользователей. После merge PR изменение состава ревьюверов запрещено.

## Запуск
```bash
git clone https://github.com/shakareem/review-assigner.git
cd review-assigner
docker compose up
```

## Допущения
- > При создании PR автоматически назначаются до двух активных ревьюверов

  При наличии в команде хотя бы двух ревьюеров, назначается два

- При добавлении новой команды с уже существующим пользователем возвращается 400 
  и новый вид ошибки USER_EXISTS, т.к. этот пользователь может быть уже назначен ревьюером 
  в другой команде и в таком случае он не должен менять команду

## Дополнительно
- Не сделана валидация тел запросов
